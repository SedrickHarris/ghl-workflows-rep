# ghl-docs (local mirror)

**Do not hand-edit.** This folder is a read-only local mirror of `ghl-docs-watcher-repo/docs/`.

It is populated by the sync scripts in `../scripts/`:

```powershell
..\scripts\sync-ghl-docs.ps1
```

```bash
../scripts/sync-ghl-docs.sh
```

Any local edits here will be overwritten on the next sync. If a doc needs to change, change it upstream in `ghl-docs-watcher-repo` and re-sync.
